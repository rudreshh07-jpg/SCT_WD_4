# Taskly — To-Do Web App

A clean, interactive, and responsive To-Do Web Application developed as part of **Task 04 of the Web Development Internship at SkillCraft Technology**.

The application helps users organize their daily tasks, set priorities and due dates, track progress, and manage completed tasks through a simple and user-friendly interface.

## ✨ Features

- ➕ Add new tasks
- ✏️ Edit existing tasks
- 🗑️ Delete tasks
- ✅ Mark tasks as completed
- 🎯 Set High, Normal, or Low priority
- 📅 Add due dates
- 🔍 Filter tasks by All, Active, and Completed
- 🧹 Clear completed tasks
- 📊 Track task completion progress
- 💾 Automatic saving using Local Storage
- 🔄 Tasks remain available after refreshing the page
- 📱 Fully responsive design for different screen sizes

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## 🚀 Run Locally

No installation is required.

1. Download or clone this repository.

```bash
git clone https://github.com/rudreshh07-jpg/SCT_WD_4.git
```

2. Open the project folder.

3. Open the `index.html` file in your web browser.

You can also use the **Live Server** extension in Visual Studio Code for a better development experience.

## 💡 How It Works

1. Enter a task in the input field.
2. Choose a priority level.
3. Optionally select a due date.
4. Add the task to your list.
5. Use the checkbox to mark a task as completed.
6. Use the edit and delete buttons to manage individual tasks.
7. Filter tasks using **All**, **Active**, or **Completed**.
8. The progress section automatically updates as tasks are completed.
9. All task data is stored in the browser using **Local Storage**.
